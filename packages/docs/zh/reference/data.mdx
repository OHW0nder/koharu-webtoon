## 支持格式

| 用途     | 格式                                |
| -------- | ----------------------------------- |
| 导入     | PNG、JPEG、WebP、CBZ、ZIP、RAR、PDF |
| 合并导出 | PNG                                 |
| 分层交换 | PSD                                 |
| 工作项目 | 应用自行选定的目录                 |

## 项目数据

每一章存放在漫画库目录下，每部漫画一个文件夹，里面每一章再一个文件夹：

```text
<漫画库>/
  demo-title/
    series.json
    Chapter 22/
      state-a.khr
      state-b.khr
      blobs/
      project.lock
```

漫画库默认为 `Documents/Koharu`，可在**设置 → 漫画库**中另行指定。改动在重启后生效，且应用不会自动搬走已有漫画：请先移动或删除它们，否则该修改会被拒绝。

每个章目录包含交替写入的持久状态文件、打开期间的锁文件，以及保存源图、生成画面和手动栅格编辑的内容寻址 blob。未被引用的 blob 不会自动移除，因此大量编辑过的章节可能随时间增大。

<Warning>章节打开时不要修改内部文件。在应用中删除章节或漫画会永久移除整个目录。</Warning>

## 设置与凭据

非秘密的类型化设置位于 `~/.koharu/config.toml`，包含流水线（含翻译）、服务商、排字、Agent 和 HTTP 超时等部分。缺失字段使用默认值；无效的手动编辑可能导致初始化失败，请优先使用设置界面。

服务凭据使用操作系统安全凭据服务。项目备份不包含密钥或 Agent 账号会话。

## 运行时与模型缓存

在 macOS 和 Linux 上，软件包位于系统缓存目录中的 `<cache>/koharu/packages/`；在 Windows 上，位于 Koharu 安装目录内的 `store` 目录。这些数据可以重新获取：关闭 Koharu 后移除它们，会让需要的软件包重新下载。

桌面进程可能仍加载原生库时，不要删除相应软件包。

## 安全备份

<Steps>
  <Step title='关闭项目'>完成当前工作后再复制文件。</Step>
  <Step title='复制完整目录'>状态文件与 blob 必须一起保存。PSD 导出不是项目备份。</Step>
  <Step title='单独保存设置'>
    需要时复制 `config.toml`，并在恢复后的设备上通过 Koharu 重新配置凭据。
  </Step>
</Steps>
