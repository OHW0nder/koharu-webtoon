## 対応形式

| 用途                 | 形式                                |
| -------------------- | ----------------------------------- |
| 読み込み             | PNG、JPEG、WebP、CBZ、ZIP、RAR、PDF |
| 統合画像             | PNG                                 |
| レイヤー付き交換形式 | PSD                                 |
| 作業プロジェクト     | アプリが選ぶディレクトリ             |

## プロジェクト

各話はライブラリフォルダーの下に保存され、作品ごとにディレクトリ、その中に話ごとのディレクトリがあります。

```text
<ライブラリ>/
  Demo Title/
    series.json
    Chapter 22/
      state-a.khr
      state-b.khr
      blobs/
      project.lock
```

ライブラリフォルダーの初期値は `Documents/Koharu` で、**設定 → ライブラリ**から変更できます。変更は再起動後に反映され、既存の作品は自動的に移動されません。先に移動または削除してください。変更が拒否されます。

各話のディレクトリには、交互に書き込む状態ファイル、プロジェクトを開いている間のロックファイル、元画像、生成画像、手動ラスター編集用の内容アドレス方式の blob が含まれます。参照されなくなった blob は自動では削除されないため、編集の多い話は時間とともに大きくなることがあります。

<Warning>
  開いているプロジェクトの内部ファイルを変更しないでください。アプリから作品や話を削除すると、そのディレクトリ全体が完全に削除されます。
</Warning>

## 設定と資格情報

秘密でない型付き設定は `~/.koharu/config.toml` にあり、パイプライン（翻訳を含む）、プロバイダー、組版、Agent、HTTP タイムアウトのセクションがあります。未指定の設定には既定値を使います。不正な手動編集は初期化失敗の原因になるため、設定画面を使ってください。

資格情報は OS の安全な資格情報サービスへ保存します。プロジェクトのバックアップにキーや Agent のアカウントセッションは含まれません。

## ランタイムとモデルのキャッシュ

macOS と Linux では OS キャッシュ内の `<cache>/koharu/packages/`、Windows では Koharu のインストールディレクトリ内の `store` ディレクトリに保存します。このデータは再取得可能で、Koharu を閉じた状態で削除すると、必要なパッケージを再取得します。

プロセスがネイティブライブラリを読み込んでいる可能性がある間は削除しないでください。

## バックアップ

<Steps>
  <Step title='プロジェクトを閉じる'>作業を終えてからファイルをコピーします。</Step>
  <Step title='ディレクトリ全体をコピーする'>
    状態ファイルと blob を一緒に保存します。PSD はプロジェクトのバックアップではありません。
  </Step>
  <Step title='設定を別に保存する'>
    必要なら `config.toml` をコピーします。復元先の端末では Koharu から資格情報を設定し直します。
  </Step>
</Steps>
