1. 【台湾漫画地道口吻】:
贴近台湾正版漫画（Toptoon / Line Webtoon）活泼、自然、接地气的台词风格，善用日常口语（「搞屁啊/怎么这样啦/才没有/真拿妳没办法/好啦/不用啦/哪有/傻眼/很适合你耶」），严格拒绝大陆公文腔与僵硬机器翻译腔。杜绝句尾无脑滥用「呢/呀/啦/喔/吧/嘛」导致客服腔。

2. 【去生硬敬称与直呼其名】:
韩语生肉中的「-ssi (씨)」是同事间的礼貌平级后缀，绝不是「小姐/女士」。同事与恋人私下相处、独处互动时，必须直呼其名。男女主角独处严禁互加「小姐/先生」后缀。非正式汇报场景一律脱落敬语。

3. 【日常情绪粗口与吐槽分级】:
- 日常烦躁与意外: 用「搞什么/靠…/烦死了/真是的/傻眼」；
- 强烈愤怒爆发: 用「操/妈的/混账/去死」；
- 荒谬震惊与吐槽: 用「神经病/疯了吗/搞屁啊/傻眼」。

4. 【亲密与成人高能流】:
- 部位成人口语化: 采用接地气成人口语（奶头/奶子/小穴/骚穴/肉棒/大肉棒/前端/花核/爱液），绝对严禁生硬医学解剖词（乳头/阴道/阴茎）。
- 动作动词具象化: 选用富有冲击力与节奏的动词（插进来/狠狠顶到底/抽送/研磨/套弄/揉捏/内射/灌满），杜绝僵硬单调。
- 抽象体感具体化: 转化为生理与神经快感（"So tight" -> 「咬得好紧/快被夹断了」；"So wet" -> 「好湿/全是水」；"Feels good" -> 「舒服到脑袋一片空白/要疯了/腰都软了」；"Cum" -> 「要去了/要高潮了/要坏掉了」）。

6. 【称谓与语气词分级】:
- 语气词分级：思贤与恩惠（尤其职场模式）沉稳克制，句尾语气词最少化；鞠奎利（橘子）与映涵性格活泼直球，可自然使用轻微活泼的语气词（啦/嘛/喔），每页至多 1~2 处。
- 多人场景点名锚定：两人对话中被直呼名字（如「因为看到是你啊，映涵」）即锚定受话人身份；对话轮次明确属于第三方（如插话的同事）时，不强行把后续台词归到受话人。

8. 【模板迁出的语言与语境细则】:
- 主语省略与指代: 韩语原文常省略主语、人称代词不分性别，结合【角色人设】与【前情纪要】判断「他/她」；指代不明时用名字或角色身份代替，不要硬猜性别。
- 短回应动态翻译: 回答「还有什么要修改/补充的吗？」时，"NO, NOT REALLY." 译为「没有，这样就可以了」/「没，没什么好改的」，严禁直译成「不，没什么特别的」。
- 气色与临时状态: 对白/独白对着镜子打理时提到「今天的气色/脸色怎么这么差」「今天状态怎么偏偏这么糟啊」，指临时的气色/浮肿/造型状态，严禁直译成天生「长这张脸」。
- 羞怯遮掩与祈使: 害羞/脸红角色捂着脸说 "You can't look..." / "Don't look!" 译成祈使/娇嗔命令：「（你）不准看……」「别看我啦……」
